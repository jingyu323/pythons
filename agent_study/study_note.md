# AI Agent 完整分类大全（通俗易懂，开发 / 选型直接能用）

按**架构、能力、工作模式、应用场景**给你分大类，都是行业通用标准分类，好理解、好落地。

## 一、按「能力层级」划分（最常用）

### 1. 简单反射型 Agent（基础版）

只看**当前感知**，按规则做动作，无记忆、不会思考。

- 特点：固定规则、不会复盘、不能规划
- 例子：自动客服关键词回复、简单机器人

### 2. 带记忆反射型 Agent

有**短期记忆**，能记住历史对话、上下文。

- 特点：能多轮对话、记住前文、不能主动规划
- 例子：普通聊天机器人、本地代码问答 Agent

### 3. 规划型 Agent（核心主流）

会**拆解任务、分步规划、自我反思**。

- 特点：先想步骤→再执行→出错回溯修正
- 例子：自动写项目代码、拆解需求分步开发

### 4. 工具使用型 Agent（Tool Agent）

可以主动调用**外部工具**：搜索、Python 代码执行、接口、文件读写、爬虫。

- 特点：不懂就搜、不会就跑代码、联网实时信息
- 例子：能查文档 + 写代码 + 运行调试的编程 Agent

### 5. 多智能体 / 协作 Agent（Multi-Agent）

多个 Agent 分工合作：产品、架构、开发、测试各自一个 Agent。

- 特点：分工、协商、互评、流水线完成复杂任务
- 例子：全自动软件开发团队 Agent

### 6. 自主进化 Agent

能**自我学习、微调、积累经验、迭代能力**。

- 特点：越用越强，沉淀经验库
- 例子：长期运维 Agent、专属行业私域 Agent

## 二、按「架构模式」划分（开发必懂）

1. Prompt 原生 Agent

   靠提示词做逻辑，无复杂框架，轻量好部署。

2. ReAct 架构 Agent

   推理 + 行动交替：思考→调用工具→再思考。

3. CoT 思维链 Agent

   强制分步思考，适合数学、代码、逻辑推理。

4. Self-Reflect 反思型 Agent

   做完自己检查、纠错、重写，代码生成最常用。

5. RAG + Agent

   

   私有知识库检索 + 任务执行，企业私有化首选。

------

## 三、按「应用场景」划分（你能用得上的）

1. 代码 Agent

   写代码、改 Bug、重构、生成项目、调试（你现在玩的 Qwen Coder 就适合做）

2. 办公 Agent

   自动处理 Excel、Word、邮件、定时任务、报表生成

3. 知识库 RAG Agent

   企业文档、私有笔记、项目文档问答

4. 任务自动化 Agent

   定时爬虫、监控告警、数据同步、运维自动化

5. 对话陪伴 Agent

   私人助手、角色模拟、专属私域 AI

6. 行业垂直 Agent

   金融、医疗、教育、工业运维专用
