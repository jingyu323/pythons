## temperature=0.1 作用详解
1. 核心含义
temperature 是生成随机性参数，取值范围：0 ~ 1
越接近 0：模型输出确定、严谨、重复度低、创造力弱
越接近 1：模型天马行空、脑洞大、容易编造、逻辑不稳定

2. MinerU  文档解析 Rag 生成文档

3. 向量片段 如何匹配

- 利用向量模型根据语义将文本转换为向量
- 通过计算向量相似度来判断语义相似度
- 块越小向量语义越精准，块越大向量语义越泛化

文本切割 
- 固定长度 
  - CharacterTextSplitter 支持字符长度  、 token长度
- 递归切割
- 文本结构切割
- markdown 文本切割 
    适用场景
适合：技术文档、教程、产品手册等有清晰标题层级的 Markdown 文件。
不适合：纯文本流水账、没有标题结构的文档
