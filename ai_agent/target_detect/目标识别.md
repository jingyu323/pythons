# 目标识别 图像检测

- 技术路线
    - 视觉
      实时/边缘设备：YOLOv8/v10/v11/v12 的 n/s 小模型，或 RF-DETR-Nano；配量化、蒸馏。
      精度优先/复杂场景：Faster R-CNN、RT-DETR-R50/R101、RF-DETR；Transformer 系在 mAP 上普遍高于同规模 YOLO，小目标优势更明显。
      要落地省心：DETR 系免 NMS，少一堆阈值调参；YOLO 系生态最成熟（导出 ONNX/TensorRT 最顺）。
    - 非视觉 雷达
      雷达/红外/SAR 目标识别常走“信号处理 + CNN/Transformer 融合”，多模态（可见光+深度/雷达）融合是当前主流方向；小样本时靠迁移学习、数据增强。


- 铁路等高精度识别
  服务器端要精度，就用 DETR/Faster R-CNN 大模型 + 高分辨率 + SAHI 切片 + 两阶段“部件→状态”，YOLO 留作基线和对照。
